Using the Workshop Workspace

The workspace buttons form a 2×2 grid: Notes / Books above Workshop / Library. Select a workspace to open its main area. Switching and restarting retain the selected Note, Book page, Workshop page and Library resource.

Select Workshop, then choose a page from the sidebar:

  • Run: literature discovery, expansion and reading tasks.

  • Templates: reading questions and output structures.

  • Outputs: generated drafts and their archive destinations.

  • Chat: ordinary conversation and source-cited document questions.

  • AI Settings: AI connection and model configuration.

A Coming soon page provides orientation and has no active task or model controls. Use enabled actions only when they are available.

Ctrl+Q switches Notes and Books; from Workshop or Library it returns to the most recently used writing workspace. Ctrl+N creates writing pages and Ctrl+E switches Edit/Preview only in Notes or Books. Dialogs keep their keyboard handling while open.

使用 Workshop 工作区¶

工作区入口按 2×2 排列：上行为 Notes / Books，下行为 Workshop / Library。选择入口后显示对应主区域。切换和重启后保留所选 Note、Book 页面、Workshop 子页和 Library 资源。

选择 Workshop 后，从侧边栏进入：

  • Run：文献发现、资料扩展和阅读任务。

  • Templates：阅读问题与输出结构。

  • Outputs：生成稿及其归档去向。

  • Chat：使用已配置模型进行普通聊天和带引用的资料问答。

  • AI Settings：AI 连接与模型配置。

标记 Coming soon 的页面用于了解功能位置，尚未提供任务或模型操作；请在操作可用时使用对应功能。

Ctrl+Q 在 Notes 与 Books 之间切换，在 Workshop 或 Library 中按下时返回最近使用的写作工作区。Ctrl+N 创建写作页面、Ctrl+E 切换 Edit/Preview，均仅在 Notes 或 Books 中生效。对话框打开时保留其键盘操作。
