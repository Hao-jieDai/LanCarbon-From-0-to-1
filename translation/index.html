Selection Translation

Translate an English word, phrase or short passage into Chinese without leaving your writing or reading page. It works in Notes and Books, PDF/EPUB text, Workshop, Library and selectable interface text. It is intended for short selections, not whole-book translation.

Translation connections and models¶

Open Workshop → Translation Settings.

Connection modeConfiguration
Use an existing AI connectionChoose a service and one of the models already saved in AI Settings. The key and model name are reused.
Separate translation connectionConfigure a dedicated service/key and translation model independently of the Chat model list.

In reuse mode, add missing models in AI Settings first. In separate mode, choose SiliconFlow, OpenRouter or Others, supply the required connection details, and choose a model with Refresh translation models or enter its exact Model ID. Refresh retrieves the platform catalogue; access and prices still depend on your account.

The example reuses a saved connection. You can instead choose a different model or key solely for translation.

Translation prompt and connection test¶

Expand Translation prompt to inspect the translation instructions. The default asks for translation of the selected content; you can adjust terminology or wording preferences. These instructions belong to translation and do not change the response guidelines used by Chat.

Click Save translation settings, then Test translation. The test displays its sample source and translated result so you can check the connection. It uses the selected service and can incur a fee. Choose a model that responds quickly enough for short selections; a large reasoning model is not automatically a better fit for this task.

Enabling translation and selecting text¶

  1. Turn on Translate in the main sidebar, or press Ctrl+Alt+T. It starts off each time LanCarbon opens.

  2. Select an English word, phrase or short passage. In an editor, select the characters inside the text field; in a reader, select readable text.

  3. After the selection settles, the floating panel shows the original and its Chinese translation. Drag the header to move it; long source and translated text scroll independently.

  4. Close the panel, turn off Translate or use the shortcut again to stop automatic translation on selection.

Password, API-key and connection-address fields are excluded. Scanned PDF text must first be recognized; see Reading PDF and EPUB.

Cached translations and usage¶

Saved translation results can be reused without repeating the same request when the text and relevant settings match. Clear translation cache removes saved translations, not your source text. Usage records and shared-account balance settings are described in Usage, Costs and Balances.

选词翻译¶

无需离开当前写作或阅读页面，就能把英文单词、词组或短段落翻译成中文。它适用于 Notes、Books、PDF／EPUB 文字、Workshop、Library 和可选取的界面文字，主要用于短内容，不是整本书的批量翻译工具。

翻译连接与模型¶

打开 Workshop → Translation Settings。

连接模式配置方法
Use an existing AI connection选择服务及 AI Settings 已保存的模型，复用密钥和模型名称。
Separate translation connection单独配置翻译服务、密钥和模型，与聊天模型列表独立。

复用模式下，缺少的模型先到 AI Settings 添加。独立模式下选择 SiliconFlow、OpenRouter 或 Others，填写连接信息，再通过 Refresh translation models 选择模型或手填准确的 Model ID。刷新得到的是平台目录，实际权限和价格仍取决于账户。

图中复用了已有连接。也可以为翻译单独选择其他模型或密钥。

翻译提示词与连接测试¶

展开 Translation prompt 查看翻译指令。默认要求翻译选中的内容，可按需调整术语或表达偏好。这里的指令只用于翻译，不会改变 Chat 的回答规范。

点击 Save translation settings，再点击 Test translation。测试会显示示例原文及翻译结果，方便检查连接；它使用选定服务，可能产生费用。短选词需要合适的响应速度，大型推理模型不一定更适合这一任务。

开启翻译并选取文字¶

  1. 开启主侧栏 Translate，或按 Ctrl+Alt+T。每次启动 LanCarbon 时默认关闭。

  2. 选取英文单词、词组或短段落。编辑器中可以选择输入框内的字符；阅读器中选择可读取的文字。

  3. 选取稳定后，浮窗显示原文和中文。拖动标题栏可以移动浮窗；长原文与长译文分别滚动。

  4. 关闭浮窗、关闭 Translate，或再次按快捷键，即可停止选词自动翻译。

密码、API Key 和接口地址字段不参与翻译。扫描 PDF 需要先识别文字，参见阅读 PDF 与 EPUB。

翻译缓存与用量¶

当选中文字及相关设置相同时，已保存的翻译结果可以复用，避免重复请求。Clear translation cache 清理已保存译文，不删除原文。用量记录与共享账户余额设置见用量、费用与余额。
