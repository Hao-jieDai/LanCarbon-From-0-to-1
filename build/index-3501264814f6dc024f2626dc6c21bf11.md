# 5. Your First Sample Book

This section turns the preceding explanations into one small project. You will create **My First Carbon Book**, give every page a stable location, practice most editor tools, check the result in Preview, build a local website, and optionally publish it.

The sample is intentionally small:

- **Home** — introduces the Book.
- **Getting Started** — contains two short learning pages.
- **Practice and Resources** — contains a formatting playground, a resource page, and a final checklist.

```text
My First Carbon Book
├─ Getting Started
│  ├─ Why Carbon Matters
│  └─ My First Observation
└─ Practice and Resources
   ├─ Formatting Playground
   ├─ Resources and Sources
   └─ Final Checklist
```

Work through the child pages in order. Values marked **copy exactly** prevent path and label mistakes. Values marked **replace** should use your own name or GitHub account.

:::{tip}
Keep this tutorial open while creating the sample in another Book. LanCarbon saves each edit automatically, so wait for **All changes saved** before changing pages or closing the application.
:::

## What this sample exercises

| Area | Practice |
| :--- | :--- |
| Structure | Home page, two Sections, six Child Pages |
| Metadata | Book Settings and Page Properties |
| Text toolbar | headings, emphasis, roles, lists, quote, link, code, table, math, separator, directives |
| Resource toolbar | image, image settings, attachment, Resources, citation workflow |
| Output | Preview, optional Export, Build, and Publish |

# 5. 你的第一本样例 Book

本节把前面的说明变成一个可以实际完成的小项目。你将创建 **My First Carbon Book**，为每个页面设置稳定路径，练习编辑器中的大部分工具，在 Preview 中检查结果，构建本地网站，并可选择发布到网上。

样例的结构特意保持简单：

- **Home**：介绍这本 Book。
- **Getting Started**：包含两篇简短学习页面。
- **Practice and Resources**：包含格式练习、资源页面和最终清单。

```text
My First Carbon Book
├─ Getting Started
│  ├─ Why Carbon Matters
│  └─ My First Observation
└─ Practice and Resources
   ├─ Formatting Playground
   ├─ Resources and Sources
   └─ Final Checklist
```

请按子页面顺序操作。标记为 **copy exactly（原样填写）** 的内容可以避免路径和 label 错误；标记为 **replace（替换）** 的内容应改成你的姓名或 GitHub 账号。

:::{tip}
创建样例时，可以保持本教程页面打开，再切换到另一本文档操作。LanCarbon 会自动保存，但切换页面或关闭软件前应等待 **All changes saved**。
:::

## 样例覆盖的功能

| 范围 | 练习内容 |
| :--- | :--- |
| 结构 | 首页、两个 Section、六个 Child Page |
| 元数据 | Book Settings 与 Page Properties |
| 正文工具栏 | 标题、强调、行内角色、列表、引用、链接、代码、表格、数学、分隔线、Directives |
| 资源工具栏 | 图片、图片设置、附件、Resources、引用文献流程 |
