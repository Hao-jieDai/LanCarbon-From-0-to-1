# Building the Book Locally

Build turns the current Book stored in LanCarbon into the same class of website that will later be published. It runs preflight checks, calls the official Jupyter Book 2 command-line tool, preserves the last successful website if a new attempt fails, and serves the result at a local address while LanCarbon is running.

---



# 在本地 Build Book

Build 会把 LanCarbon 当前保存的 Book 转换成以后用于发布的网站。它先执行 preflight 检查，再调用官方 Jupyter Book 2 命令行工具；如果新一次构建失败，会保留上一次成功的网站；LanCarbon 运行期间，还会通过本地地址提供网站预览。
