# Managing and Reading Documents in Library

Library stores imported PDF and EPUB documents alongside the images and attachments used in Notes and Books. This section explains how to import and organize files, handle duplicates and versions, and keep document references connected to your writing.

The built-in readers open PDF and EPUB documents inside LanCarbon. They provide document navigation, search, multiple file tabs and text selection; local OCR makes scanned PDF text available for reading and translation.

---

# 使用 Library 管理与阅读资料

Library 保存导入的 PDF、EPUB，以及 Notes 和 Books 使用的图片与附件。本节介绍文件导入与整理、重复文件和版本管理，以及文档与写作内容之间的引用关系。

内置阅读器可以直接打开 PDF 和 EPUB，提供目录、搜索、多文件标签和文字选取功能。本地 OCR 则为扫描 PDF 提供可用于阅读和翻译的识别文字。
