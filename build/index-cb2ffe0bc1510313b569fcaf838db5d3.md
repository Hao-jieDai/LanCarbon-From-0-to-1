# Installation, Requirements, and Basic Concepts

This section prepares your computer and gives you a mental model of the whole workflow. Start here even if LanCarbon is already installed. A successful launch only proves that the desktop application can run; Build and Publish use additional tools that are checked in their own windows.

After this section, you should know where LanCarbon stores data, what each external tool does, and where to find the main controls.

---



# 安装、使用要求与基本概念

本 Section 用于准备电脑并建立完整流程的基本认识。即使你已经安装 LanCarbon，也建议从这里开始。软件能够正常启动，只代表桌面程序本身可以运行；Build 和 Publish 还会使用额外工具，并分别在对应窗口中检查。

完成本 Section 后，你应该了解 LanCarbon 在哪里保存数据、每项外部工具负责什么，以及主界面的关键控制位于哪里。
