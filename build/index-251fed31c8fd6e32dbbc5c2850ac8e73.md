# Creating, Writing, and Exporting a Book

This section creates the actual source of your first Book. You will build a table of contents, set metadata, learn the Markdown/MyST features exposed by the toolbars, manage resources, use Preview, and make an optional source export.

The authoritative Book is the copy saved inside LanCarbon. Export is useful for backup or external editing, but it is not required before Build or Publish.

---



# 创建、撰写与导出 Book

本 Section 将创建第一本 Book 的实际内容。你会建立目录、填写元数据、学习工具栏对应的 Markdown/MyST 功能、管理资源、使用 Preview，并按需导出源文件副本。

LanCarbon 内部保存的 Book 是软件工作流中的正式版本。Export 适合备份或在外部编辑，但 Build 和 Publish 前并不要求先 Export。
