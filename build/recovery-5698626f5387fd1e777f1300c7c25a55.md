# Backing Up and Recovering Your Work

## Make a complete backup

Before an upgrade or a major move:

1. Wait for **All changes saved**, then close LanCarbon.
2. Back up the actual **Data Location**, **Config** and **Cache/Local State**, which is needed alongside encrypted AI settings. Include root **Library** and any **Builds**, **Exports** or **PDFs** you need to keep.
3. Keep a known working installer with the backup.
4. Verify that the backup can be read and restored into a separate folder before replacing your daily installation.

## Restore a compatible copy

Application recovery and data recovery work together. An older application may require the matching data snapshot. Restoring a snapshot returns to the backup date; preserve any newer edits separately first. Use an empty recovery folder so existing work is not overwritten.

The built-in tutorial is system-managed. Its official content is synchronized on startup; your personal Notes and Books are the material to preserve in a writing backup. A backup is not a way to retain edits to the system tutorial.

If LanCarbon reports an unsupported workspace format, close it and use a compatible application or a verified recovery copy. Keep the original data until recovery has been checked.

# 备份与恢复写作资料

## 创建完整备份

升级或大规模迁移前：

1. 等待 **All changes saved**，然后关闭 LanCarbon。
2. 备份实际 **Data Location**、**Config** 和加密 AI 设置所需的 **Cache/Local State**，一并包含根目录 **Library**，以及需要保留的 **Builds**、**Exports** 或 **PDFs**。
3. 将已知可用的安装包与备份一起保存。
4. 覆盖日常安装前，先验证备份可读，并能恢复到独立目录。

## 恢复兼容的副本

恢复程序和恢复数据需要配合。旧程序可能需要对应的数据快照。恢复快照会回到备份时的状态，请先另行保留后续新增编辑。使用空的恢复目录，避免覆盖已有内容。

内置教程由软件管理，官方内容会在启动时同步；写作备份应保护用户自行创建的 Notes 和 Books。备份不能用于保留对系统教程的自行修改。

如果 LanCarbon 提示不支持当前工作区格式，请关闭软件，使用兼容程序或经过验证的恢复副本；恢复检查完成前保留原始数据。
