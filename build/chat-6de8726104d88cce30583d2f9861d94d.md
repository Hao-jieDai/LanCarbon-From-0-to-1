# Working with AI Chat

## Creating a chat

After [configuring a model](ai-settings.md), open **Workshop → Chat** and choose **New chat**. Select the service and model above the messages. Type your question in the message box; **Enter** sends it and **Shift+Enter** inserts a line break.

Ordinary Chat does not require sources. Questions about your own documents use the source selection described in [Questions about Your Knowledge Library](knowledge.md).

## Follow-up questions, model switching and stopping

Ask follow-up questions in the same conversation when they depend on earlier discussion. You can change the model before the next message. Each answer retains its model label; switching does not erase the conversation history. The new model may use earlier replies as context, so use separate new chats for independent model comparisons.

**Stop generating** stops an active answer and preserves the received part. **Retry reply** starts a new request, so it may incur another charge. Switching to Notes or Books allows generation to continue; closing LanCarbon stops it. Use **Rename chat** for a useful title and **Delete chat** when you no longer need that conversation.

## Text, formulas and Thinking

Replies support Markdown, code blocks and LaTeX formulas. **Copy** preserves the Markdown/LaTeX source; paste it into a Note and use **Preview** to read the formatted content. Inline math uses single dollar delimiters; display math uses double-dollar delimiters on separate lines. If an answer uses an unformatted plain-text equation, ask for LaTeX rather than expecting Copy to infer its structure.

For models that return reasoning text, **Thinking / Reasoning** appears separately and can be expanded. This is the reasoning text supplied by the service; not all models return it. Collapsing it changes the display, not the saved contents.

## Exporting to PDF or Note

| Action | Result |
| --- | --- |
| **Export PDF** | Save a readable copy of the conversation, normally starting in the PDFs folder. |
| **Export to Note** | Create a new editable Note from the conversation and open its Preview. |
| **Copy** | Copy an individual message for use in your own writing. |

Wait for generation to finish or stop it before exporting. **Include Thinking** includes the saved reasoning even if collapsed on screen. **Include cited evidence excerpts** adds the referenced passages for source-based answers. The export retains speaker/model information and source locations. Exports are local and make no additional model request.

Each exported Note is an independent snapshot. Later chat messages do not modify it. Review and edit that Note, then add it to your own Book if you want to organize it with other reading notes. See [Creating Your First Book](../02-authoring/create-first-book.md) for writing organization.

# 使用 AI Chat

## 新建聊天

[配置模型](ai-settings.md)后，打开 **Workshop → Chat**，点击 **New chat**。在消息区上方选择服务和模型，在输入框填写问题。**Enter** 发送，**Shift+Enter** 换行。

普通 Chat 不要求选择来源。围绕自己的文档提问时，需要选择对应资料，具体操作见[基于个人知识库提问](knowledge.md)。

## 追问、切换模型与停止生成

需要沿用前文时，在同一聊天继续追问。发送下一条消息前可以切换模型；每条回答保留自己的模型标签，切换不会清空聊天历史。新模型可能将之前的回答作为上下文，因此独立比较不同模型时，应分别新建聊天。

**Stop generating** 停止当前回答并保留已收到的部分；**Retry reply** 会重新发起请求，可能再次产生费用。切换到 Notes 或 Books 时可以继续生成，关闭 LanCarbon 会停止。使用 **Rename chat** 命名聊天，不再需要时使用 **Delete chat**。

## 正文、公式与 Thinking

回答支持 Markdown、代码块和 LaTeX 公式。**Copy** 保留 Markdown／LaTeX 源文本，粘贴到 Note 后可在 **Preview** 中阅读排版结果。行内公式使用单个美元符号包围，独立公式使用单独成行的双美元符号。回答中若是没有格式的纯文本公式，可以要求模型改为 LaTeX，不要依赖复制操作自动推断公式结构。

模型返回推理文字时，会单独显示可展开的 **Thinking / Reasoning**。这是服务实际提供的内容，并非所有模型都会返回。收起只影响显示，不删除已保存的文字。

## 导出 PDF 或 Note

| 操作 | 结果 |
| --- | --- |
| **Export PDF** | 将对话保存为便于阅读的 PDF，保存位置默认从 PDFs 文件夹开始。 |
| **Export to Note** | 根据对话创建新的可编辑 Note，并打开 Preview。 |
| **Copy** | 复制单条消息，整理进自己的写作。 |

导出前请等待生成结束或先停止。勾选 **Include Thinking** 会导出已保存的推理文字，即使它在界面上处于收起状态。**Include cited evidence excerpts** 可加入资料回答引用的原文片段。导出保留发言者、模型及来源位置，在本地完成，不增加模型调用。

每次导出的 Note 都是独立快照，不随后续聊天自动更新。可以检查和编辑后，将它加入自己的 Book，与其他阅读笔记一起整理。写作组织方法见[创建第一本 Book](../02-authoring/create-first-book.md)。
