## English

# Write the Home and Content Pages

Use the following short drafts as a starting point. Type them with the toolbar where practical instead of pasting everything. This lets you learn how the visible controls change Markdown source.

## Home page

```markdown
# My First Carbon Book

Welcome to **My First Carbon Book**. This small project records what I learn about carbon and gives me a place to practice LanCarbon.

## What you will find

- a short explanation of carbon;
- one personal observation;
- a formatting and resource practice area.

> Small, verified steps make a reliable Book.
```

## Getting Started Section page

```markdown
# Getting Started

This Section introduces the topic before the detailed pages.

1. Read **Why Carbon Matters**.
2. Continue to **My First Observation**.
3. Use Preview after each edit.
```

## Why Carbon Matters

```markdown
# Why Carbon Matters

Carbon is part of living organisms, the atmosphere, oceans, rocks, and soils. Human activities can move carbon between these stores.

## A simple balance

Net change can be described as emissions minus removals:

$$
\Delta C = E - R
$$

:::{note}
This equation is a learning model. Real carbon accounting needs clearly defined boundaries, units, and data sources.
:::
```
