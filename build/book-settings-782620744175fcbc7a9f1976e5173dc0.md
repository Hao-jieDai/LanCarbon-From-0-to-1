## English

# Enter the Book Settings

Select **Settings** while `My First Carbon Book` is active. Use the table below. The first version avoids optional branding so it can build immediately.

| Field | Value for this sample | Required? | Meaning and rule |
| :--- | :--- | :---: | :--- |
| Book title | `My First Carbon Book` | Yes | Main identity of the Book. Keep it concise. |
| Subtitle | `A Small Practice Book Built with LanCarbon` | No | One-line explanation shown with the Book metadata. |
| Description | `A beginner project for practicing structured writing, local building, and online publishing with LanCarbon.` | No | Summary for readers and generated metadata. |
| Authors | **Replace:** `Your Name` | Recommended | Use the name you want readers to see. Multiple authors can be entered as supported by the dialog. |
| GitHub repository URL | Leave blank now | No for Build | Add `https://github.com/YOUR-ACCOUNT/my-first-carbon-book` after the repository exists. Do not copy another person's account. |
| License | `CC-BY-4.0` | No | Use only if you want to permit reuse under that license. Leave blank if you have not chosen a license. |
| Keywords | `carbon, climate, learning, LanCarbon` | No | Search and description terms. Use short, relevant phrases. |
| Site title | `My First Carbon Book` | No | Browser and website title. Matching the Book title is simplest. |
| Logo Path | Leave blank | No | Set later only when a suitable image is managed by the Book and the path is valid. |
| Favicon Path | Leave blank | No | Set later only when a valid icon resource exists. |

Click **Save Settings**, wait for the save indicator, reopen **Settings**, and confirm every value persisted.

:::{warning} Do not copy account-specific values
The repository URL shown elsewhere in this guide belongs to the guide author. Your sample must use your own GitHub account and repository name.
:::

## What can be changed later?

Descriptive fields can be edited later. Stable names and URLs reduce confusion once a Book has been published. Changing the visible title is normally safe; changing the repository name or publication address requires corresponding GitHub changes.

## 中文

# 填写 Book Settings

确保当前 Book 是 `My First Carbon Book`，然后点击 **Settings**。请按下表填写。第一版先不设置可选的品牌图片，以便立即构建。

| 字段 | 本样例填写值 | 是否必填 | 含义与规则 |
| :--- | :--- | :---: | :--- |
| Book title | `My First Carbon Book` | 是 | Book 的主要名称，应简洁明确。 |
| Subtitle | `A Small Practice Book Built with LanCarbon` | 否 | 对 Book 的一行说明。 |
| Description | `A beginner project for practicing structured writing, local building, and online publishing with LanCarbon.` | 否 | 提供给读者和生成元数据的摘要。 |
| Authors | **替换为：** `Your Name` | 建议填写 | 填写希望读者看到的姓名。对话框支持时可以填写多位作者。 |
| GitHub repository URL | 暂时留空 | Build 不需要 | 仓库创建后填写 `https://github.com/你的账号/my-first-carbon-book`，不要照抄他人账号。 |
| License | `CC-BY-4.0` | 否 | 仅在你确实希望按该许可授权复用时填写；尚未决定则留空。 |
| Keywords | `carbon, climate, learning, LanCarbon` | 否 | 用于描述和检索的短关键词。 |
| Site title | `My First Carbon Book` | 否 | 浏览器和网站标题。新手可与 Book title 保持一致。 |
| Logo Path | 留空 | 否 | 只有在 Book 已管理合适图片且路径有效时再设置。 |
| Favicon Path | 留空 | 否 | 只有在有效图标资源存在时再设置。 |

点击 **Save Settings**，等待保存状态完成，再次打开 **Settings**，确认所有内容已经保存。

:::{warning} 不要照抄他人的账号信息
本教程其他截图中的仓库地址属于教程作者。你的样例必须使用自己的 GitHub 账号和仓库名。
:::

## 后续可以修改吗？

描述类字段可以后续修改。Book 发布后，保持名称和网址稳定能减少混淆。修改可见标题通常没有问题；修改仓库名或发布地址则需要同步调整 GitHub 设置。
