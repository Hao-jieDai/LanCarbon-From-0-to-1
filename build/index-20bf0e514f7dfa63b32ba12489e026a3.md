# Using Workshop

Workshop provides AI Chat, selection translation, and usage and cost tracking. This section explains service and model configuration, conversation management, translation settings, and the records used to estimate costs and account balances.

Chat can also use selected Library documents, Notes and Book pages to answer questions and compare material. Source citations lead back to the original content, and conversations can be exported as PDF or saved as editable Notes.

---

# 使用 Workshop

Workshop 提供 AI Chat、选词翻译，以及用量和费用统计。本节介绍服务与模型配置、聊天管理、翻译设置，以及费用和账户余额的记录方式。

Chat 也可以使用选定的 Library 文档、Notes 和 Book 页面回答问题或比较资料。通过来源引用可以返回原文；对话结果可以导出为 PDF，或保存为可继续编辑的 Note。
