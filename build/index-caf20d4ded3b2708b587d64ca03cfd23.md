## English

# Publishing the Book Online

Publish copies the latest successful local website to a GitHub repository branch and configures GitHub Pages to serve that branch. The first publication establishes the connection; later publications update the same website while keeping Git commit history.

---

## 中文

# 在线 Publish Book

Publish 会把最新成功的本地网站复制到 GitHub 仓库的发布分支，并配置 GitHub Pages 使用该分支。第一次发布负责建立连接；后续发布会更新同一个网站，并保留 Git commit 历史。
