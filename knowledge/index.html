Document Questions / 资料问答

Document Questions¶

Open Workshop → Chat. Choose a Chat model, then use Choose sources above the message box. Notes appear as a list; Books expand into chapters and pages; Library folders expand into subfolders and files. Arrows expand without selecting. Book, chapter and folder checkboxes select their contents; individual items can be excluded. Search and folding preserve selection. A source referenced more than once is counted once. Whole-Book and folder selections include later additions; chapter/page selections retain the selected pages. Include linked attachments follows references without copying Library originals. Enable Show built-in content to select the official tutorial. Import PDF / EPUB, or dropping files into Chat, imports or reuses Library originals and selects them.

Sources are remembered per chat. Clear sources returns to ordinary Chat; changing the selection excludes prior document answers from the new scope. Stop generating cancels preparation and generation. No separate Knowledge base page is required.

Full-text questions¶

When Evidence shows PaperQA · full text, LanCarbon reads all available parsed text from the selected sources. Choose any configured Chat model from SiliconFlow, OpenRouter or Others. The selected service must support Chat Completions and have enough context capacity for your sources; access and context limits are determined by that service. You can switch models in the chat selector without changing your sources. Embedding and Rerank are not needed in this mode. PaperQA organizes the complete original passages for one answer; it does not generate a summary, plan, quotation map or second rewritten answer. Recent completed conversation turns from the same selection are included for follow-up questions. Each turn checks the current source texts; previous answers are conversation context, not additional evidence.

If the selected texts are too large, missing or only partly parsed, the request stops before sending. Reduce the selection or check the source/OCR; no part is silently omitted. Full text means successfully extracted text, not verified visual coverage of every table or scanned page. Sending whole texts can cost more input tokens than sending a few retrieved passages. Usage records the Chat request, including returned Thinking usage. No retrieval requests are added by this mode.

The installed application includes the local PaperQA runtime; no separate Python, Docker or WSL installation is required. Existing model connections and files are reused.

Retrieval settings¶

Saved retrieval connections remain available in settings and old chat records retain their retrieval labels. PaperQA full-text questions do not use these connections. For a build using the retrieval mode, configure Embedding and optional Rerank in AI Settings → Retrieval. Refresh the appropriate model catalogue, save and test the chosen model; catalogue availability does not guarantee account access. When you ask a question, extraction, changed-source checks and vector preparation run automatically. Existing vectors are reused when the text and embedding model are unchanged. Retrieval selects passages within a bounded context, so selection does not mean the whole source was sent. Evidence identifies semantic retrieval, reranking or keyword fallback. Auxiliary requests and failed attempts appear in Usage. Local text/index tools provide optional inspection and cache clearing; clearing derived indexes preserves originals and chats.

Reading assistance¶

Use document questions to locate passages, explain concepts and compare studies. Before incorporating a conclusion into research, open its citation and check the original amount and unit, formula variable definitions, scenario and who owns or bears the reported loss. A local calculation can check arithmetic, but does not establish that the model selected the right entity or scenario.

Read and check citations¶

Replies cite saved passages as [S1], [S2], etc. Click a citation or expand Evidence → Open source to open its PDF page, EPUB chapter, or Note/Book source lines. Evidence distinguishes cited passages from other included passages. Moving or renaming a source preserves its identity; editing or deleting the original prevents outdated navigation while retaining the saved passage. Citation checks identify unavailable sources and missing or unknown labels, not whether a model’s scientific interpretation is correct. Verify important amounts, units, methods and comparisons against the actual original.

Text extraction supports text-based/scanned PDF, reflowable EPUB and Note/Book Markdown. Scanned pages can use local English/Chinese OCR; check important numbers and formulas visually. Encrypted PDFs, DRM/fixed-layout EPUB, Word and standalone images are not supported as indexed sources. Preparation has bounded per-source and total capacity; large selections can require narrowing. Local extraction makes no model API calls. Sending a document question transmits the selected context to your configured service and incurs that service’s charges. Copies and chat exports retain the existing Markdown/LaTeX workflow; PDF and Note exports can include Thinking.

资料问答¶

进入 Workshop → Chat，选择聊天模型，再点击输入框上方的 Choose sources。Notes 按列表显示；Books 按整本书、章节、页面展开；Library 按文件夹、子文件夹和文件展开。箭头只展开目录；勾选整书、章节或文件夹可选中其内容，也可单独排除条目。搜索和折叠保留选择，同一来源重复引用只计算一次。整本 Book 和文件夹包含之后新增的内容；章节和页面选择保留当时选中的页面。Include linked attachments 跟随附件引用，不复制 Library 原件。勾选 Show built-in content 可选择官方教程。Import PDF / EPUB 或拖入文件会导入或复用 Library 原件并选中。

资料范围按聊天保存。Clear sources 回到普通聊天；更换选择后，之前的资料回答不进入新范围。Stop generating 取消准备和生成，无需单独操作 Knowledge base 页面。

全文问答¶

当 Evidence 显示 PaperQA · full text 时，软件读取选定资料的全部可用解析文本。可选择 SiliconFlow、OpenRouter 或 Others 中已配置的聊天模型；所选服务须支持 Chat Completions，并有足够的上下文容量，模型权限和容量以服务端为准。可在聊天模型选择框切换模型，无需重新选择资料。此模式不需要 Embedding 和 Rerank。PaperQA 将完整原文组织为一次回答的输入，不先生成摘要、规划、引文定位表或第二次改写答案。同一资料选择下近期已完成的对话可用于追问，每轮核对当前原文；以前的回答只是对话上下文，不是新的证据。

资料过大、缺失或仅完成部分解析时，会在发送前停止。请缩小选择或检查原文/OCR，不会悄悄省略一部分。全文指成功提取的文字，不代表每个表格或扫描页的视觉内容均已核验。全文输入可能比少量检索片段消耗更多输入 token。Usage 记录这一次 Chat 请求及接口返回的 Thinking 用量，此模式不额外发起检索请求。

安装版内置本地 PaperQA 运行环境，无需另装 Python、Docker 或 WSL；现有模型连接与文件可直接复用。

检索设置¶

已保存的检索连接继续保留，旧聊天保留原来的检索标识。PaperQA 全文问答不使用这些连接。在使用检索模式的构建中，可在 AI Settings → Retrieval 配置 Embedding 和可选 Rerank。刷新相应模型目录、保存并测试；目录中可见不代表账号一定有权限。提问时自动提取文字、检查变更并准备向量；文字和嵌入模型未变时复用向量。检索在有限上下文中选择片段，选中资料并不代表整篇已发送。Evidence 显示语义检索、重排或关键词回退，辅助调用及失败请求计入 Usage。本地文本与索引工具可检查和清理缓存，清理衍生索引不会删除原件和聊天。

辅助阅读¶

资料问答适合定位段落、解释概念和比较文献。将结论写入研究前，打开引用检查原文金额与单位、公式变量定义、情景及损失由谁持有或承担。本地计算可以核对算术，不能证明模型选对了主体或情景。

阅读并核对引用¶

回答以 [S1]、[S2] 等引用保存的原文。点击引用或 Evidence → Open source 可打开 PDF 页、EPUB 章节或 Note/Book 对应行。Evidence 区分实际引用与其他已纳入的原文。移动、重命名保留来源身份；编辑或删除原件会阻止旧引用错误跳转，但聊天中保留当时的文本。来源和引用检查可识别文件不可用、标签缺失或未知，不能判定模型的学术解释是否正确。重要金额、单位、方法和比较结论应核对原文。

支持文字/扫描 PDF、流式 EPUB 和 Note/Book Markdown。扫描页可使用本地中英文 OCR，关键数字和公式仍应查看原页。加密 PDF、DRM/固定版式 EPUB、Word 和独立图片暂不作为可索引来源。单篇及总文本容量有上限，大范围选择可能需要缩小。本地解析不调用模型；发送资料问题会将选定上下文交给已配置的服务并产生费用。复制和导出沿用 Markdown/LaTeX 流程，PDF 和 Note 导出可包含 Thinking。

Checking monetary amounts / 核对金额¶

Source-linked amounts: Clearly identified monetary values can be rendered and converted locally from their original source quantities. Differences and percentage reductions use those same operands without another model call. Check amounts lists calculations that could not be matched or completed; these notes remain in copies and PDF/Note exports. Unclear units and flagged OCR are not guessed. These checks cover monetary representation and arithmetic, not whether the chosen scenario, entity or economic comparison is correct.

原文金额核对： 明确识别的金额可根据原文数量在本地显示和换算，差额与降幅也由对应操作数计算，不增加模型调用。Check amounts 会列出无法匹配或完成的具体计算，复制及 PDF／Note 导出会保留这些说明。单位不清楚、OCR 存疑时不猜测换算。核对范围是金额表示和算术，不代表情景、主体或经济比较已经验证正确。
