Enter the Book Settings

Select Settings while My First Carbon Book is active. Use the table below. The first version avoids optional branding so it can build immediately.

FieldValue for this sampleRequired?Meaning and rule
Book titleMy First Carbon BookYesMain identity of the Book. Keep it concise.
SubtitleA Small Practice Book Built with LanCarbonNoOne-line explanation shown with the Book metadata.
DescriptionA beginner project for practicing structured writing, local building, and online publishing with LanCarbon.NoSummary for readers and generated metadata.
AuthorsReplace: Your NameRecommendedUse the name you want readers to see. Multiple authors can be entered as supported by the dialog.
GitHub repository URLLeave blank nowNo for BuildAdd https://github.com/YOUR-ACCOUNT/my-first-carbon-book after the repository exists. Do not copy another person’s account.
LicenseCC-BY-4.0NoUse only if you want to permit reuse under that license. Leave blank if you have not chosen a license.
Keywordscarbon, climate, learning, LanCarbonNoSearch and description terms. Use short, relevant phrases.
Site titleMy First Carbon BookNoBrowser and website title. Matching the Book title is simplest.
Logo PathLeave blankNoSet later only when a suitable image is managed by the Book and the path is valid.
Favicon PathLeave blankNoSet later only when a valid icon resource exists.

Click Save Settings, wait for the save indicator, reopen Settings, and confirm every value persisted.

Do not copy account-specific values

The repository URL shown elsewhere in this guide belongs to the guide author. Your sample must use your own GitHub account and repository name.

What can be changed later?¶

Descriptive fields can be edited later. Stable names and URLs reduce confusion once a Book has been published. Changing the visible title is normally safe; changing the repository name or publication address requires corresponding GitHub changes.

填写 Book Settings¶

确保当前 Book 是 My First Carbon Book，然后点击 Settings。请按下表填写。第一版先不设置可选的品牌图片，以便立即构建。

字段本样例填写值是否必填含义与规则
Book titleMy First Carbon Book是Book 的主要名称，应简洁明确。
SubtitleA Small Practice Book Built with LanCarbon否对 Book 的一行说明。
DescriptionA beginner project for practicing structured writing, local building, and online publishing with LanCarbon.否提供给读者和生成元数据的摘要。
Authors替换为： Your Name建议填写填写希望读者看到的姓名。对话框支持时可以填写多位作者。
GitHub repository URL暂时留空Build 不需要仓库创建后填写 https://github.com/你的账号/my-first-carbon-book，不要照抄他人账号。
LicenseCC-BY-4.0否仅在你确实希望按该许可授权复用时填写；尚未决定则留空。
Keywordscarbon, climate, learning, LanCarbon否用于描述和检索的短关键词。
Site titleMy First Carbon Book否浏览器和网站标题。新手可与 Book title 保持一致。
Logo Path留空否只有在 Book 已管理合适图片且路径有效时再设置。
Favicon Path留空否只有在有效图标资源存在时再设置。

点击 Save Settings，等待保存状态完成，再次打开 Settings，确认所有内容已经保存。

不要照抄他人的账号信息

本教程其他截图中的仓库地址属于教程作者。你的样例必须使用自己的 GitHub 账号和仓库名。

后续可以修改吗？¶

描述类字段可以后续修改。Book 发布后，保持名称和网址稳定能减少混淆。修改可见标题通常没有问题；修改仓库名或发布地址则需要同步调整 GitHub 设置。
