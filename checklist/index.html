Complete First-Book Checklist

English¶

Complete First-Book Checklist¶

Use this page as the final acceptance list.

Content¶

  • The Book has a clear home page, Sections, and Child Pages.

  • Every page has a unique, stable Export Path.

  • Headings, lists, tables, directives, math, and links work in Preview.

  • Every image has useful alternative text; captions and alignment are correct.

  • Resources shows no missing managed files.

  • No private information or unfinished placeholder will be public.

Build¶

  • Python 3 passes.

  • Jupyter Book CLI v2 passes.

  • Preflight has zero errors; warnings were reviewed.

  • Build is up to date.

  • Open Website shows correct navigation and complete content.

Publish¶

  • Git and GitHub CLI pass.

  • GitHub account is the intended owner.

  • GitHub API and Git HTTPS connection pass.

  • Repository binding is the intended owner/name.

  • GitHub Pages shows the expected URL.

  • Published website shows a new time and commit.

  • Open Pages displays the current Book, not a README, stale revision, or BASE_URL warning.

  • Public navigation, images, downloads, and links work.

Congratulations: your first Book has moved from local writing to a verified online website. Keep editing the authoritative Book in LanCarbon; use Rebuild Website and Update Website for future releases.

中文¶

第一本 Book 完整验收清单¶

请把本页作为最终验收列表。

内容¶

  • Book 有明确的首页、Sections 与 Child Pages。

  • 每页都有唯一且稳定的 Export Path。

  • 标题、列表、表格、Directives、数学公式和链接在 Preview 中正常。

  • 每张图片都有有效替代文字，caption 与对齐正确。

  • Resources 中没有缺失的受管理文件。

  • 不会把隐私内容或未完成占位文字公开。

Build¶

  • Python 3 检查通过。

  • Jupyter Book CLI v2 检查通过。

  • Preflight 为 0 error；所有 warning 均已检查。

  • Build is up to date。

  • Open Website 显示正确导航与完整内容。

Publish¶

  • Git 与 GitHub CLI 通过。

  • GitHub account 是预期 owner。

  • GitHub API 与 Git HTTPS connection 通过。

  • Repository binding 是预期的 owner/name。

  • GitHub Pages 显示预期网址。

  • Published website 显示新的时间与 commit。

  • Open Pages 显示当前 Book，而不是 README、旧版本或 BASE_URL 警告。

  • 公开网站中的导航、图片、下载和链接均正常。

恭喜，你的第一本 Book 已经从本地写作变成经过验证的在线网站。以后继续在 LanCarbon 中编辑正式 Book，再通过 Rebuild Website 与 Update Website 发布新版本。
